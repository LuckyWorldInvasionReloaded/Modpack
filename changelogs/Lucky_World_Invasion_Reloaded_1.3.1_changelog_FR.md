# Lucky World Invasion Reloaded 1.3.1

## Corrections
- Les distributeurs trouvés dans le monde vendaient toujours du stock Outils, quel que soit leur type. Ils vendent maintenant ce qu'ils annoncent. Les machines déjà ouvertes gardent leur ancien stock — la relance du marchand (10 niveaux) les corrige.
- Les Lucky Events ne plaçaient aucun lucky block quand tu étais en pleine eau. Ils apparaissent maintenant dans l'eau autour de toi.

## Changements
- Les vies partagées se règlent dans la config Lucky Tweaks : vies de base, plus vies par joueur en coop. Par joueur à 0 = toute l'équipe sur un seul pool partagé. Défauts inchangés (solo 1, duo 3, trio 4).
- La conversion de machine du marchand donne un type aléatoire au lieu d'un ordre fixe (jamais le type actuel).
