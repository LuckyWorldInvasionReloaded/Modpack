# Lucky Tweaks 1.0.11

- Fixed the Ender Dragon getting stuck at its low base health (~600 HP instead of ~2000+) for a whole fight - it happened mostly on servers, when the server had (re)started while the dragon was already damaged. The dragon now always gets its full fight health boost on the first hit.
- The Luck line on lucky item tooltips now always displays in English ("Luck: +X"), whatever the game language.
- When an item's Luck has reached its block's cap, the value shows as "+X (max)" in gold - a fully infused block reads at a glance. Other values keep the usual colours (green positive, red negative).
- Fuze Relics' lucky block is renamed "Fuze Lucky Block" (was "Lucky Blockling").
