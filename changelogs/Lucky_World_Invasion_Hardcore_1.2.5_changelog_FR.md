# Lucky World Invasion Hardcore - Mise à jour 1.2.5 proposée

## Nouveaux outils Lucky (3)

Le **Tools Lucky Block** droppe désormais **8 outils** (les 5 d'origine + les 3 ci-dessous) :

- **Lucky Hammer** — sacrifie 30 lucky blocks (casse-les en le tenant : ils ne droppent rien, c'est le coût) pour charger le marteau, puis utilise-le **une seule fois à l'enclume** sur une arme ou une armure : réparation totale + véritable indestructibilité (Solidité 100 + Unbreakable). Usage unique.
- **Lucky Ring** — anneau (équipement Curios). Tant qu'il est porté, **chaque lucky block cassé augmente un peu ta chance générale** (jusqu'à +30 %, rendements décroissants : impactant tôt, jamais trop fort au bout de centaines de blocs). Tout ce que tu casses devient plus chanceux ; le % actuel est affiché sur l'anneau.
- **Lucky Belt** — ceinture (équipement Curios, style mécano). Tant qu'elle est portée, **double tes chances de jackpot sur les Tools Lucky Blocks**.

L'anneau et la ceinture sont des **équipements Curios** : portables en même temps dans leurs slots dédiés (clic droit pour équiper), et compatibles avec tous les autres lucky tools. Curios est déjà fourni par le modpack.
