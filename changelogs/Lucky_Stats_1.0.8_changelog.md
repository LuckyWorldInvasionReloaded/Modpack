# Lucky Stats 1.0.8

- HUD editor: new "HUD scale" setting that resizes the whole HUD at once - text AND layout scale together, so stacked lines never overlap. Each line still has its own individual size on top of it.
- Every line in the editor list now shows its position: the preset's name (Top-Left, Mid-Center...) while it actually sits on one, "Custom" once you have dragged it elsewhere. Unpinned lines show their position too.
- The editor list is more compact and its panel adapts to its content, so it fits on screen at the pack's default GUI scale.
