# Lucky Tweaks 1.1.1

## Shared lives are now fully configurable
The Lives tab of the config screen now has two dials instead of one fixed rule:
- **Base lives** — what the run starts with, solo or co-op alike.
- **Extra lives per player (co-op)** — what each player adds once the run is co-op. This part used to be fixed at one per player and could not be changed.

Set the per-player dial to **0** and team size stops mattering: a whole team then plays on exactly the base you chose — a **single shared life** for everyone, if that is how you want to play.

Defaults are unchanged: solo still runs on 1 life, a duo on 3, a trio on 4.
