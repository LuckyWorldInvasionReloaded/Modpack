# Lucky Tweaks 1.0.9

- Legendary & cursed drops: plays a suspense effect on legendary drops and feeds the Lucky Stats counters (the cursed counter is delayed so it doesn't spoil the draw).
- Crocodile no longer destroys the weapon it swallows: it drops it back when killed (toggle: fixCrocodile).
- Fixed an Enhanced AI "open doors" server crash (a mob with no ground navigation).
- Fixed a Yakurum armor tooltip crash with LootBeams (item dropped while sneaking).
- Added an option to neutralize PlayerRevive, off by default so death stays hardcore.
