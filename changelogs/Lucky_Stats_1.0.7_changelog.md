# Lucky Stats 1.0.7

## Day + time
- The "Day" stat now also shows the in-game time, formatted "Day 1, 15:30" (24-hour clock, from the overworld so it stays correct in other dimensions). Shown both on the HUD and on the stats screen. The time updates in 5-minute steps so it doesn't flicker every second.
- The day number is now 1-indexed (a new world starts at "Day 1").
